# Uthmani Hafs font

Place the QCF Hafs v2 / Uthmanic Hafs font file here as `UthmanicHafs1Ver18.ttf`.

Suggested source: https://qurancomplex.gov.sa/en/techquran/dev/ (King Fahd Complex — licensed for non-commercial use).
Alternative: the `uthmanic_hafs` Flutter package.

If the font is missing at build time, Flutter will fall back to the system Arabic font; the app will still run but text will not look like a Mushaf.
